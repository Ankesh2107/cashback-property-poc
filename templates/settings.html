How it works

With API key: Gemini 3.1 Flash Lite generates personalized outreach emails and reply scenarios tailored to each lead's name, company, role and city.

Without API key: The system uses template-based drafts with placeholders. These still include the correct name/company but are less personalized.

Caching: AI-generated content is cached in the database. Click "Regenerate" on any lead to get fresh content.
